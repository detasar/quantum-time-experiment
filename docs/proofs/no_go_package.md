# No-Go Package

## N1 — Label permutation
Local record fidelity identifies an unordered outcome alphabet. Any simultaneous permutation of clock labels and record labels leaves local record statistics invariant.

## N2 — Orientation swap
A two-tick GHZ record state distinguishes the Z basis but not which outcome is earlier. Orientation needs a blank/present write asymmetry or another directed structure.

## N3 — Unrestricted partition
If arbitrary global Hilbert-space refactorizations are admissible, subsystem locality and redundant fragments are not invariant. Clock objectivity is therefore relative to a physically justified partition class.

## N4 — One-record ambiguity
A maximally entangled clock-record pair gives perfect conjugate correlations in every basis. One fragment alone cannot select a preferred basis.

## G1 counterexample catalog

`results/processed/counterexample_catalog.json` stores the smallest explicit
examples used by the tests and report. Each entry maps one failed assumption to
the conclusion that is no longer licensed.
